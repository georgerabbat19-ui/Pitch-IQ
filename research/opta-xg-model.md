# Opta xG & xGOT Model Research
_Researched: 2026-03-15_

## xG Model (Current)
- Uses **XGBoost** ML, trained on ~1 million historical shots
- **20+ variables** including: distance, angle, assist type, body part, shot type, pattern of play, **defensive pressure**, **goalkeeper position**, **number of defenders between ball and goal**
- Separate model for women's football
- Source: https://www.statsperform.com/resource/expected-goals-xg-the-football-metric-changing-analysis-betting-and-fan-engagement/

## Why Old Info Said Pressure/Defenders Weren't Included
- Original 2019 page (https://www.statsperform.com/resource/expected-goals-in-context/) describes basic model: distance, angle, header, big chance only
- Event definitions page (https://www.statsperform.com/opta-event-definitions/) still shows old simple definition — never updated
- StatsBomb marketed their 360 freeze-frame data (defender positions) as superior to Opta ~2018-2021 — that narrative stuck
- Opta upgraded their model via **Opta Vision** (XY tracking) — new variables added, old docs never updated

## Two Opta xG Products
1. **Public xG** — event data + pressure flag (what Sky Sports, The Analyst show)
2. **Opta Vision xG** — full spatial tracking of all players, sold to clubs/broadcasters

## Historical Data Caveat
- Tracking data (Opta Vision) wasn't collected retroactively
- Pre-2019/20 data: upgraded model falls back to event-data variables only — pressure/defender positioning fields will be null
- 2017-18 xG figures in Boss's dataset likely generated by the old model
- Check for `pressure` field / defender count field being null on old shots to confirm

## xGOT Model
- **Post-shot** model — measures likelihood of on-target shot becoming a goal
- Variables: original xG + shot end location in goalmouth (coordinates) + shot trajectory
- Enhanced Sep 2025: separate men's/women's models, dedicated penalties model (20k+ penalties)
- **GK position:** More relevant to xG (pre-shot) than xGOT (post-shot)
- Opta event data does record `GK Y Coordinate` qualifier — whether xGOT uses it as a feature is not publicly confirmed
- Original xGOT assumed GK at center of goal
